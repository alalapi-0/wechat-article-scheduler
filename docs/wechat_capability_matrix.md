# 微信能力矩阵

本表描述仓库能力，不代表当前公众号账号一定拥有对应接口权限。账号权限、微信规则和接口返回必须在用户授权的 real 检查中单独确认。

| 能力 | mock | real | 最终责任 |
|---|---:|---:|---|
| 文章导入、去重、排期 | 是 | 是 | 本项目 |
| Markdown/TXT/HTML 渲染 | 是 | 是 | 本项目 |
| 摘要长度兜底 | 是 | 是 | 本项目 |
| 单篇/默认封面检查 | 是 | 是 | 本项目 |
| token 获取与内存缓存 | 否 | 是 | 微信 API |
| 永久素材封面上传 | 模拟 | 是 | 微信 API |
| draft/add 创建草稿 | 模拟 | 是 | 微信 API |
| draft/update 更新草稿 | 模拟 | 是 | 微信 API |
| 草稿列表同步 | 本地模拟 | draft/batchget，只读 | 微信 API + 本地镜像 |
| 已发布列表能力探测 | 本地模拟 | freepublish/batchget，只读 | 微信 API |
| 远端草稿删除 | 否 | 不实现 | 用户在后台人工完成 |
| 后台合集、通知等非 API 字段核对 | 否 | 任务包/人工 | 用户或外部 Agent |
| 后台定时发布设置 | 否 | 人工 | 用户 |
| 最终发布、群发 | 否 | 不实现 | 用户 |
| 发布 proof | 本地记录 | 用户提供 | 用户 |

field-matrix CLI 与 GET /api/wechat-field-matrix 提供字段级机器可读说明。任何标为待核验或人工的字段都不能因为 UI 中存在输入项而宣称 API 已支持。

## 明确边界

- freepublish/batchget 可用于只读同步；它与 freepublish/submit 是不同接口。
- 项目不包含 freepublish/submit 或 draft/delete 调用，也没有启用它们的开关。
- 草稿复用、更新和 proof 必须匹配原任务与 `mock/real` 来源；来源不明的历史草稿按 `unknown` 处理，不能冒充真实草稿。
- 本地 scheduled_at 只决定 scheduler 何时创建/更新草稿，不会写入微信后台定时发布时间。
- 封面裁剪预览是本地辅助信息，最终显示效果应在公众号后台核对。
- 外部浏览器只允许定位、对比、截图和报告；最终按钮由用户操作。
