# Backlog

本文件只记录未来可能性，不是当前路线图、承诺或运行时接口。任何候选能力都必须先有新的用户目标、权限确认、平台条款与最小验收标准，才能重新进入代码。

## 可能评估

- 更完整的微信公众号 HTML 排版和预览一致性。
- 封面可视化裁剪与双比例预览。
- 多合集排期规则与批量编辑体验。
- 与只读检查报告相互独立的真实 proof 导入校验。
- 经过独立产品决策后的其他内容平台。

## 明确不提前实现

- 通用 adapter registry、manifest、content package 或跨项目 calendar。
- 知乎、豆瓣、小红书、视频号、Bilibili、抖音、快手、博客或 Webhook runtime。
- 内置浏览器 Agent、cookie/session 存储或验证码自动化。
- 自动审核、auto-approve、占位 proof。
- 微信最终发布、群发或后台定时发布确认。

历史预研与 round 记录可通过 Git 历史查看，不再作为当前仓库权威。
